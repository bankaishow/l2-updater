# Правила для Kimi (апдейтер клиента L2)

Ты пишешь апдейтер клиента Lineage 2 для Windows вместе с Claude. Владелец не программист: отвечай по-русски, простыми словами, давай точные команды, не больше 5 вопросов за раз.

## 1. Где что

| Что | Где |
|---|---|
| Твоя папка | `/home/kimi/l2-updater` (свой клон, ветка `main`) |
| .NET 8 SDK | `~/.dotnet/dotnet` (добавь `export PATH=$HOME/.dotnet:$PATH` в `~/.bashrc`) |
| Задачи | `docs/tasks.md` (ставит Claude, статусы меняет только Claude) |
| Твой журнал | `docs/worklog.md` (новые записи сверху) |
| Обмен с Claude | `/tmp/kimi-handoff/` (Claude кладёт bundle и патчи; ты их применяешь сам) |

- Работаешь под отдельным пользователем Linux `kimi`. Чужие папки (`/home/john`, `/home/gemini`) тебе недоступны: не ищи их и не пытайся получить доступ.
- **Push не делаешь** (ключа GitHub у тебя нет). Claude забирает твои коммиты из твоей папки, проверяет и публикует.
- **Репозиторий публичный** (открытый код, лицензия MIT). Поэтому в нём никогда не должно быть: паролей, ключей, закрытого ключа подписи, адресов внутренней сети (192.168.*), личных данных. Тестовые ключи для тестов генерируются в самих тестах.
- Docker, sudo, подключения к игровым серверам и базам — нельзя и не нужно.

## 2. Как работать

1. Перед началом: `git log --oneline -5`, `git status`, прочитать `docs/tasks.md` (первая задача «к работе») и `docs/plan.md`.
2. Код в `src/`, тесты в `tests/`. Команды по одной, без `cd` в начале и без склейки через `&&`.
3. Перед коммитом: `dotnet build` без ошибок и предупреждений о безопасности, `dotnet test` зелёный.
4. Запись в `docs/worklog.md`: что сделано, файлы, что проверено, что проверить на Windows (владелец), вопросы.
5. Коммит, сказать владельцу: «К-N готова» и номер коммита.
6. Вопросы — в раздел «Вопросы к Claude» в `docs/tasks.md`, и останавливаться только если без ответа никак; иначе брать следующую задачу.

## 3. Правила кода

- C# .NET 8, nullable включён, предупреждения как ошибки в `L2Updater.Core`.
- `L2Updater.Core` — без Windows-зависимостей (собирается и тестируется на Linux): формат манифеста, проверка подписи, проверка путей, хеши, план обновления, загрузка. `L2Updater.App` — WinForms, только интерфейс.
- Только встроенная криптография .NET (`ECDsa` P-256, `SHA256`), без сторонних библиотек для криптографии. Сторонние пакеты — только с согласия Claude.
- Безопасность важнее удобства (раздел «Безопасность» в `docs/plan.md`): сначала проверка подписи, потом всё остальное; путь из списка файлов никогда не выходит за папку игры; файл заменяется только после проверки SHA-256; только `https://`.
- Комментарии в коде по-английски, коротко.
